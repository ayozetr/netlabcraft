# UI parity

> **Last reviewed:** 2026-10-30 · **Last updated:** 2026-10-30 · **Change:** minor (complex PDUs, the OSI Model view, scenarios, the Programming app, PoE, SIP, IoT and cloud windows; figures aligned with ROADMAP.md) · **Target:** Cisco Packet Tracer 9.0

The window, element by element, against the reference app. Part of
[target-app-parity.md](target-app-parity.md). The arrangement was observed black-box (local
`plan/packet-tracer/observed-ui.md`); artwork and wording are ours. **Workspace and windows:
~83% ready, 12–20 h; Simulation mode: ~85% ready, 6–12 h** (estimated; the same figures as
[`ROADMAP.md`](../ROADMAP.md#dimensions)).

| Element | Reference app | NetLabCraft |
|---|---|---|
| Menu bar | File, Edit, Options, View, Tools, Extensions, Window, Help | same menus, our items; File ▸ Open Recent on the desktop; File ▸ Print… makes an A4 PDF of the workspace and opens it in the system's PDF viewer to print (the web build downloads it); the web build asks before closing a tab with unsaved changes |
| Main toolbar | file, print, info, copy/paste, undo/redo, zoom, palette… ; help at right | new, open, save, network information, copy/paste devices, undo, redo, zoom in/reset/out, capture export; help at right |
| Second toolbar | select, inspect, delete, resize, note, drawing, simple/complex PDU | select, inspect, delete, place note, line, rectangle, ellipse, freehand, polygon, simple PDU, complex PDU (also under Tools), group into a cluster; resize shown but not available yet |
| Workspace bar | Logical / Physical, coordinates, Root, navigation, clock | Logical / Physical, coordinates, a clickable Root › cluster › … path with back, clock |
| Opening a lab | the view as saved | a lab that opens or is created is fitted to the workspace: centred and zoomed out (never past 1:1) with room for labels and notes; opening a cluster and switching views fit the same way |
| Workspace | white, icons with model + name, port labels, link triangles; red serial cables with a clock at the DCE; EtherChannel marks | same arrangement, icons drawn in code; device names on a soft plate, port labels kept clear of name blocks and of each other; parallel cables side by side, a ring around each EtherChannel, red zigzag serial cables with a clock at the DCE end, a router mark on multilayer switches |
| Time bar | time, power cycle, fast forward; Realtime / Simulation | same; the right-hand tabs are placed first and the hint and captions give way, so nothing overlaps in either language or mode (tested) |
| Device box | categories, search, subcategories, model tiles, model name box | same; 37 models of our own (routers, modular routers, a firewall, switches incl. a multilayer one, one with fiber uplinks and two with PoE, a home router and a home gateway, an access point, a wireless controller and lightweight APs, a hub, PCs, laptops incl. Wi-Fi, a server, a printer, an IP phone, eight IoT things; a WAN Emulation group with the cloud and the DSL and cable modems) in wrapping rows with two-line names; the cable tiles (coaxial and phone too) are under Connections |
| Scenario / PDU list | scenario, New/Delete, PDU table | scenario menu (Scenario 0, 1, …) with New and Delete, each scenario keeping its own PDUs in the lab file; Fire All; PDU table (Fire, Last Status, Source, Destination, Type, Color, Time, Periodic, Num, Delete) |
| Create Complex PDU | source, application, destination, ports, TTL, TOS, sequence number, size, one-shot or periodic with a time | a window from the toolbar and the Tools menu: source device and port, application (ping, DNS, HTTP, Telnet, SSH, FTP, SMTP, POP3, DHCP, TFTP, SNMP, ARP, raw UDP or TCP), destination, ports, TTL, TOS or DSCP, sequence number, size, the DNS name, page, file or community, one-shot or periodic with a start time counted from now (no absolute start time) |
| Simulation Panel | event list (Vis., Time, Last/At Device, Type, Info), Reset Simulation, play controls with speed, filters, Edit Filters / Show All/None; time bar with ms and play controls, Event List toggle | same arrangement, with columns that fit the panel; protocol frames (BPDUs, OSPF, RIP, EIGRP, HSRP, LLDP, LACP, DHCP, DNS, TCP…) listed with their own filters and colours; plus drop reasons and pcap export; no Constant Delay option |
| PDU information | OSI model and per-layer details | opens on an OSI Model view: In and Out layers with the decode and what the receiver decided (MAC table, routing lookup, TTL, ARP, access lists, NAT; up to 8 steps), then Inbound and Outbound PDU details and the hex dump; opens below the toolbars. The origin device's own decisions are not recorded (only receivers') |
| Router/switch window | Physical, Config, CLI, Attributes | same tabs; Config: bordered list with bold sections; Global Settings with Display Name and Hostname, NVRAM Erase/Save, Startup Config Load/Export, Running Config Export/Merge; VLAN database, static routes, interfaces; console output underneath |
| PC window | Physical, Config, Desktop, Programming, Attributes | Physical, Config, Desktop (navy desktop with tiles: IP Configuration with DHCP/Static and IPv6 Off/Automatic/Static, Command Prompt, Web Browser, Email, MIB Browser, Terminal over a console cable, Programming), Attributes; only working apps are shown. Programming is a Desktop app rather than a tab: RESTCONF mode (method, URL, Basic login, headers, JSON body, saved requests, answers with status, headers and a folding JSON viewer), NETCONF mode (framing and operations) and Controller mode (managed routers, push a template); it sends requests, it doesn't run scripts |
| Server window | Physical, Config, Services (HTTP, DHCP, DHCPv6, TFTP, DNS, SYSLOG, AAA, NTP, EMAIL, FTP, IoT…), Desktop, Programming, Attributes | Physical, Config, Services (HTTP with file manager, DHCP pools, DNS records, SYSLOG messages, NTP, TFTP files, AAA clients and users, FTP accounts and files, EMAIL domain and users), an IoT tab for the IoT service (things listed live, webcam stills, rules in words with several conditions), Desktop with the Programming app, Attributes |
| Home gateway, phones, PoE switches, cloud | own pages per device | the Home Gateway has the home router's page and an IoT tab; the Phone tab has a dial pad and a Signal with SIP box; Physical tabs show a powered device's adapter plug and power source, a PoE switch's budget and lit PoE ports, a cloud's port pairs, a router's switch card with link lights |
| Web Browser | URL bar with back/forward, Go, Stop; page view | same; renders headings, paragraphs, bold, lists and links |
| Activities | Instructions window with timer and score, Check Results tree, Reset Activity; Activity Wizard with answer network | Instructions window with Completion, a timer, Check Results per section (several rows visible), Compare with the Answer (each check's answer next to the lab, answers kept back when hidden) and Reset Activity; Activity Wizard (title, instructions, values per student, capture answers, ping/config/command/address checks, sections, hints, hidden answers, time limit, password lock); no answer-network tree |
| Clusters | grouped devices shown as one cloud; open, rename, uncluster | same: pick with Shift+drag or Shift+click, Ctrl+G groups, a code-drawn cloud with the device count, double-click to open, nesting, cables to the cloud at the parent level |
| Physical workspace | Intercity map, cities, buildings, wiring closets; cable lengths | same levels with code-drawn icons and a path bar (Intercity › City › Building › Closet); new places, rename, remove, move devices between places; cables between places labelled with their length, copper over 100 m goes down and says why; lengths from the places or set by hand; fiber runs up to 2 km. Once a lab has a layout, a Wi-Fi host reaches only the access points of its own building (walls, not metres, decide) |
| Connections | cable types in the device box | Automatic, Console, Copper Straight-Through, Copper Cross-Over, Fiber, Serial DCE, Serial DTE, Coaxial and Phone tiles with drawn glyphs; the port menu greys out ports a cable doesn't fit and says why; each kind drawn its own way; the PC's Terminal app over a console cable |
| Dialogs | open over the workspace | About, Compare with the Answer, PDU information and the Activity Wizard open below the toolbars; IP Configuration and Global Settings laid out on a grid |
| Language | English plus community files | English and Spanish; every window, tab, page and mode is swept by a test that fails on English text left untranslated ([localization-parity.md](localization-parity.md)) |
| Not yet | — | Resize Shape, Constant Delay, capturing only the filtered events, absolute PDU start times, scripts in the Programming app, the answer-network tree |
