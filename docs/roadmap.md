# Milestones

_Updated 2026-10-29._

- **M0 — Foundations (done).** Workspace, gates, wire formats, model, simulator, console, engine, UI, CLI, MCP, web.
- **M1 — Services.** DHCP, SVIs/L3 switching, DNS and a minimal HTTP server on servers; PC desktop web view.
- **M2 — Resilient LANs.** STP/RSTP, EtherChannel, port security.
- **M3 — Dynamic routing.** OSPF, then RIPv2; route redistribution basics.
- **M4 — Security.** ACLs, NAT/PAT, passwords, SSH.
- **M5 — Teaching.** Activity checks and scoring, lab instructions panel, translations.
- **Beta gates:** a CCNA-style lab book (VLANs, inter-VLAN routing, DHCP, OSPF, ACL, NAT) runs end to end, both by hand and through MCP; every gap above it is closed.
