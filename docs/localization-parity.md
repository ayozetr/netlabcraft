**Localization: ~82% ready, 8–14 h** (estimated).

The reference app ships its interface in several languages through translation files. The
storytold Craft apps share their translations through
[`craft-i18n`](https://github.com/storytold/craft-i18n); NetLabCraft uses the same catalog format and lookup rules (see [translating.md](translating.md)), embedded in every build.

| Feature | Reference app | NetLabCraft | Gap and estimate |
|---|---|---|---|
| Interface language | English plus community language files | English, Spanish, Brazilian Portuguese, French, Italian, German and Simplified Chinese (2,355 rows each, unreviewed by native speakers), and any language added as a catalog: Options ▸ Language lists every catalog by its own name, the system's language by default (the browser's on the web), remembered on the desktop | Engine errors in the status bar and the reasons a frame was dropped are translated by matching templates (`no route to {}` fits `no route to 10.0.0.1`); event summaries are translated phrase by phrase (the `event` rows of the catalog), leaving addresses, names and protocol names as they are. PDU details (layer names, fields and values) too: done |
| Catalogs | — | `locales/<locale>/netlabcraft.tsv` at the repository root, one directory per language (lowercase BCP 47: `es`, `pt-br`, `zh-hans`), in the craft-i18n row format (`context<TAB>English<TAB>translation`, `\n` for line breaks, `@id language.name`, `@plural` rows), embedded at build time so a release stays one binary; six exist (`es`, `pt-br`, `fr`, `it`, `de`, `zh-hans`), each with 2,062 rows (counted as the rows without `@id`, the `event` phrases included). A missing row shows English; a regional locale falls back to its base language. Messages with parts use `{}` (craft-i18n uses `{name}`; kept because the engine's messages are matched against the rows by position). A checker test enforces the format on every catalog (header with the `# Clean room:` line, columns, escapes, placeholder and `…` parity, duplicates, plural forms, regional rows equal to the base) and prints each catalog's coverage; tests sweep every window, tab, page and mode in Spanish and fail on English text that has a row missing or literal text without one, check that every translated literal has a row and that every row is still used | Joining `storytold/craft-i18n` itself if NetLabCraft becomes a Craft app; more languages: 4–6 h each with review |
| Device console | English (as on real equipment) | English | Stays English on purpose: commands and output are what students meet on real devices |
| Sample labs, notes and activity texts | Activity instructions per language | Sample titles, descriptions, notes and the sample activity in Spanish (a test checks every sample has its rows); notes people write stay as written; an activity's instructions can be written in several languages (`activity.translate`, a tab per language in the Activity Wizard), and the Instructions window shows the one matching the interface language, else the main one | — |
| Right-to-left scripts, CJK fonts | — | Simplified Chinese glyphs: a subset of Noto Sans CJK SC (GB2312, 1.6 MB) is the last fallback font, desktop and web; Latin text is unchanged. Everything else: egui default fonts only | Right-to-left scripts and other scripts' fonts when a catalog needs them: 3–5 h; Traditional Chinese needs its own glyphs (Big5 / HKSCS) |
| BoardScript messages | — | The language's keywords are English, like a console's; its compile and run messages (38 rows) read in the interface language in the status bar, the board page's message and its output; the engine, the console and MCP keep English | None |
| Keyboard layouts and IME | OS | egui text input | Verify dead keys (Spanish `ñ`, accents) in the console: 1–2 h |
