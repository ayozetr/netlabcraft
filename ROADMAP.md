# PacketCraft roadmap

**Stage: pre-alpha** · next: alpha, ~25–45 agent-hours away

> **Last reviewed:** 2026-10-30 · **Last updated:** 2026-10-30 · **Change:** major (rewritten in the shared roadmap format) · **Target:** Cisco Packet Tracer 9.0 (as used in CCNA courses)

PacketCraft aims at Cisco Packet Tracer parity for teaching and lab work, and at being better
in places: real frames you can open in any packet analyser, an open lab format, agent control
(MCP and CLI), and the browser. This page is the summary. The detail is in:

- [`docs/target-app-parity.md`](docs/target-app-parity.md): the authoritative assessment, method and weights
- [`docs/gaps.md`](docs/gaps.md): every known shortfall, ranked; the work list
- [`docs/roadmap.md`](docs/roadmap.md): milestones, current focus, alpha and beta gates
- [`docs/command-reference.md`](docs/command-reference.md): generated by `cargo xtask parity` (engine commands and console grammar)
- Area checklists: [protocols and commands](docs/protocol-parity.md) · [UI](docs/ui-parity.md) ·
  [hardware](docs/hardware-parity.md) · [localization](docs/localization-parity.md)
- [`docs/architecture.md`](docs/architecture.md): how it is built

## Progress log

- **2026-10-30 — Model names and equivalents.** Models are named after their ports (Router 3GE, Switch 24FE, L3 Switch 24…), and a new page says which one to place when a course lab names a vendor model; old lab files open unchanged.
- **2026-10-30 — Wireless controller and 802.11.** WLC and lightweight AP models: APs join their controller and get its WLANs; Wi-Fi hops carry real 802.11 frames with association and the WPA2 handshake; WPA2-Enterprise logins are checked by RADIUS; wlc sample lab; a separate 802.11 capture.
- **2026-10-30 — QoS.** Class maps, policy maps and service policies: DSCP marking that shows in captures, policing that drops with a reason, and per-class counters in `show policy-map interface`.
- **2026-10-30 — SNMP traps, SNMPv3 and mail relay.** Routers and switches send link-down, link-up and cold-start traps that PCs and servers list in the MIB Browser; SNMPv3 users with MD5 or SHA authentication; mail servers hand mail for other domains to the right server and bounce what can't be delivered.
- **2026-10-30 — Printing.** File ▸ Print puts the workspace on an A4 page with the lab's name and opens it in the system's PDF viewer to print; the web build downloads the PDF.
- **2026-10-30 — Events in Spanish.** With the Spanish interface, the event list's summaries and the PDU details read in Spanish too; addresses, names and protocol names stay as they are.
- **2026-10-30 — Compare with the answer.** After Check Results, the Instructions window's Compare button lists each check's answer next to what the student's lab has (the lab's side only when the answers are hidden).
- **2026-10-30 — Drawings and clusters.** Draw freehand strokes and polygons on the workspace; pick several devices (Shift+drag or Shift+click), group them into a cluster with Ctrl+G, open it with a double click and come back through the Root › … path; clusters nest and the simulation ignores them.
- **2026-10-30 — GRE tunnels and IPsec.** `interface tunnel` with GRE (OSPF runs over it) and site-to-site IPsec with ISAKMP policies, pre-shared keys, transform sets and crypto maps; ESP on the wire, `show crypto` views, and a stated reason when the two ends don't agree.
- **2026-10-30 — EIGRP.** `router eigrp` with networks, passive interfaces and router IDs; DUAL successors and feasible successors from bandwidth and delay; hellos on the wire; `show ip eigrp neighbors|topology|interfaces`; administrative distances decide between EIGRP, OSPF and RIP.
- **2026-10-30 — Contributors in About.** Help ▸ About has a Contributors tab, as in the other Craft apps: everyone who contributed, by username or by the name they chose in `contributors/people.toml`, sortable and as a list or a table.
- **2026-10-30 — SNMP.** Routers and switches run an SNMP agent (`snmp-server community`), and PCs have a MIB Browser to get, walk and set its objects.
- **2026-10-30 — TACACS+.** Logins can be checked by a TACACS+ server too (`tacacs-server host`, `group tacacs+`), with the encrypted exchange on the wire.
- **2026-10-30 — Errors in Spanish.** With the Spanish interface, the status bar's errors and the reasons a frame was dropped read in Spanish too.
- **2026-10-30 — Workspace image.** File ▸ Export Workspace Image (PNG) saves the lab as a picture, on the desktop and on the web.
- **2026-10-30 — `ip address dhcp`.** Router interfaces, routed ports and the home router's Internet port can lease their address (and a default route) from a provider's DHCP server.
- **2026-10-30 — Email.** Servers have an EMAIL service (domain, users) and PCs an Email app: set up the account, write, send and receive; Simulation mode shows the SMTP and POP3 sessions.
- **2026-10-30 — Values per student.** Activities can have variables (`{net}` in instructions and checks): each student types their name and gets their own values, so no two labs are the same; results also come per section (per device by default).
- **2026-10-30 — CCNA 1 lab commands.** Output filters (`show running-config | include …`, `section`, `begin`), `security passwords min-length`, `login block-for`, `username … privilege 15`, `speed`/`duplex`/`mdix auto` (a speed mismatch takes the link down), `delete vlan.dat`, and many more `show` commands; VLANs now live in the VLAN database as on real switches.
- **2026-10-30 — Home wireless router.** A Home-Router model: Internet port, four LAN ports and Wi-Fi, handing out addresses and translating to the Internet out of the box, with a Home Router settings page; multilayer switches also do NAT, DHCP server and ACLs.
- **2026-10-30 — Sample labs in Spanish.** The sample labs' titles, descriptions and notes, the sample activity and the status messages built from parts read in Spanish too.
- **2026-10-30 — App icon and Linux install.** PacketCraft has its own icon (window, menu, web tab) and `packaging/linux/install.sh` puts it in the desktop menu with `.pcraft` files opening in it.
- **2026-10-30 — More debugs.** `debug ip packet`, `debug ip nat` and `debug ip dhcp server events` report what the router routes, translates and hands out.
- **2026-10-30 — FTP.** Servers have an FTP service with accounts and permissions; PCs have an `ftp` client (`put`, `get`, `dir`, `delete`) and `dir` for their own files; routers copy configurations with `copy running-config ftp:`. Simulation mode shows the control and data connections.
- **2026-10-30 — AAA with RADIUS.** Routers and switches check remote logins against a RADIUS server (`aaa new-model`, `aaa authentication login default group radius local`, `radius-server host`); the Server has an AAA service with clients and users; Simulation mode shows the Access-Request and its answer.
- **2026-10-30 — OSPFv3.** OSPF for IPv6: `ipv6 router ospf`, `ipv6 ospf N area A` on interfaces, neighbours over link-local addresses, routes across areas and a default route, hellos in Simulation mode, `show ipv6 ospf neighbor`.
- **2026-10-30 — DHCPv6 relay.** `ipv6 dhcp relay destination` passes a LAN's DHCPv6 clients on to a server elsewhere; Simulation mode shows the Relay-forward and Relay-reply messages.
- **2026-10-30 — IPv6 on subinterfaces and VLAN interfaces.** Router-on-a-stick with IPv6 on each subinterface, and multilayer switches routing IPv6 between their VLAN interfaces; SLAAC, DHCPv6 and traffic filters work there too.
- **2026-10-30 — OSPF stub areas.** `area N stub` (with the hello mismatch when only one end says so), `area N stub no-summary` and `area N range` on border routers; RIP also runs on multilayer switches.
- **2026-10-30 — OSPF database exchange.** When two OSPF routers become neighbours, Simulation mode shows them exchange database descriptions, requests, updates with their router-LSAs and acknowledgements, as real routers do.
- **2026-10-30 — LACP frames.** EtherChannel ports in LACP mode exchange LACPDUs every 30 s (the passive end answers an active one), visible in Simulation mode and captures with their sync state.
- **2026-10-30 — Routing debugs.** `debug ip rip` reports each RIP update a router hears with its routes; `debug ip ospf hello` (or `adj`, `events`) the OSPF hellos; `show debugging` lists what is on.
- **2026-10-30 — LLDP.** Standard neighbour discovery (IEEE 802.1AB): `lldp run`, `lldp transmit`/`receive` per port, `show lldp neighbors [detail]`, with real LLDP frames every 30 s in Simulation mode and captures; also `show processes` and `show memory`.
- **2026-10-30 — Activity time limit and lock.** An activity can have a time limit (a countdown in the Instructions window; the results are taken when it runs out), a hint per check shown when it fails, and an instructor password that locks it: students can't change it or see its checks, and with "score only" Check Results shows just the score.
- **2026-10-30 — Spanish interface.** Menus, toolbars, panels and device windows in Spanish (Options ▸ Language; the system or browser language by default); the device consoles stay in English, as on real equipment.
- **2026-10-30 — Wi-Fi.** An AccessPoint model and a Laptop-WiFi model: SSID, open or WPA2-PSK, channel; hosts join the nearest access point in range with the same network and key, drawn as a dashed line; the access point relays between its hosts; Wi-Fi settings in the port pages and the `device.wireless` command; wifi sample lab.
- **2026-10-30 — Spanning-tree timers.** A port that starts forwarding listens 15 s and learns 15 s first (amber light, LIS/LRN in `show spanning-tree`), as on real switches; portfast and `spanning-tree mode rapid-pvst` skip the wait; sample labs start converged.
- **2026-10-30 — Safer files.** The web build asks before a tab with unsaved changes closes; the desktop keeps a File ▸ Open Recent list.
- **2026-10-30 — NTP, syslog and TFTP.** Server NTP, SYSLOG and TFTP services with their pages in the Services tab; `ntp server`, `show ntp status`, `logging host`, `copy running-config tftp:` and `copy tftp: startup-config`, all on the wire in their standard formats.
- **2026-10-30 — DHCPv6.** `ipv6 dhcp pool`, `ipv6 dhcp server` and the M/O flags in router advertisements; hosts follow them with SLAAC, stateless DHCPv6 or stateful DHCPv6, with the exchange in Simulation mode; `show ipv6 dhcp pool/binding`.
- **2026-10-30 — OSPF depth.** `ip ospf cost` and `ip ospf priority` with a real DR/BDR election, `auto-cost reference-bandwidth`, several areas with inter-area routes (`O IA`), `show ip ospf` and `show ip ospf interface [brief]`, DR/BDR in `show ip ospf neighbor`, OSPF on multilayer switches.
- **2026-10-30 — Access-list depth.** `access-class` on vty lines; IPv6 access lists (`ipv6 access-list`, `ipv6 traffic-filter`, `show ipv6 access-list`); ICMP errors translated back through NAT, so traceroute works through PAT.
- **2026-10-30 — PPP authentication.** `ppp authentication chap|pap` and `ppp pap sent-username` on serial links, checked against local usernames; a failed authentication keeps the link down and says so.
- **2026-10-30 — DTP.** `switchport mode dynamic auto|desirable` and `switchport nonegotiate`; whether a link trunks is negotiated from both ends, and every view shows the working mode.
- **2026-10-30 — HSRP.** `standby` groups with priority and preempt on router interfaces, subinterfaces and multilayer VLAN interfaces; the active router answers for the virtual address with the virtual MAC; hellos every 3 s in Simulation mode; `show standby`; hsrp sample lab.
- **2026-10-30 — Activities.** A lab can carry an activity: instructions, checks (configuration lines, pings that must succeed or fail, host addresses, command output) worth points, answers stored as hashes when hidden; an Instructions window with Completion, Check Results and Reset Activity; an Activity Wizard that captures the answers from a finished lab; activity-first-router sample.
- **2026-10-30 — Console messages and logging.** Devices report link up/down, port-security shutdowns and configuration changes in a logging buffer (`show logging`, `clear logging`) and on their console after the prompt; `debug ip icmp`, `undebug all`, `show debugging`.
- **2026-10-30 — Protocol frames in Simulation mode.** Switches send spanning-tree BPDUs every 2 s (tagged per VLAN on trunks), OSPF routers hellos every 10 s with their neighbours, DR and BDR, RIP routers updates every 30 s with split horizon; new STP, OSPF and RIP filters and colours; captures include them.
- **2026-10-30 — Everyday console commands.** Neighbour discovery (`cdp run`, `cdp enable`, `show cdp neighbors [detail]`); `clock set` and `show clock`; `show flash`/`dir flash:`, `show users`, `terminal length`; `show ip interface`, `show interfaces status`, `show interfaces X switchport`, `show running-config interface X`; a fuller `show version`.
- **2026-10-30 — Documentation in the shared Craft format.** README with screenshots; parity assessment with written weights, audiences per CCNA course and labelled estimates; ranked gaps with hours; milestones with alpha and beta gates; new protocol, hardware and localization checklists; contributors and releasing pages; a review line and revision history on every page.
- **2026-10-29 — Serial WAN links.** A Router-WAN model with serial ports; serial cables whose first end is the DCE; `clock rate`, `encapsulation hdlc|ppp`, line protocol down without a clock or with mismatched framing; `show controllers`; HDLC/PPP frames on the wire (listed and captured as Ethernet II); red serial cables with a clock at the DCE end; serial-wan sample lab.
- **2026-10-29 — RIP.** `router rip` with version, classful networks, passive interfaces, split horizon, 15-hop limit and default-route origination, computed like OSPF; R routes in `show ip route`, `show ip rip database`, RIP in `show ip protocols`; rip sample lab.
- **2026-10-29 — Multilayer switch.** A Switch-ML-24 model routes with `ip routing` between its VLAN interfaces and routed ports (`no switchport`), with static routes and `show ip route`; drawn with a small router mark; multilayer sample lab.
- **2026-10-29 — IPv6.** Real IPv6/ICMPv6/NDP frames; global, EUI-64 and link-local addresses; neighbour discovery; router advertisements and host autoconfiguration; static routes (link-local next hops too); ping and traceroute; `show ipv6 interface brief|route|neighbors`; IPv6 in the PC IP Configuration and router port pages; ipv6 sample lab.
- **2026-10-29 — VTP.** Servers, clients and transparent switches share VLANs over trunks by domain and password, highest revision first (including the classic overwrite by a switch with a higher revision); the VLAN database survives reloads; `show vtp status`; vtp sample lab.
- **2026-10-29 — EtherChannel.** `channel-group` with LACP, PAgP or static bundling, negotiated from both ends; a bundle is one spanning-tree port and spreads traffic over its cables; `interface port-channel`, `show etherchannel summary`; parallel cables drawn side by side with a ring around each bundle; switches flush learned addresses when the topology changes; etherchannel sample lab.
- **2026-10-29 — Port security, Telnet/SSH, one-click devices.** `switchport port-security` with maximum, violation modes and sticky addresses; ports go err-disabled and come back with `shutdown`/`no shutdown`; `show port-security`. Remote consoles over Telnet and SSH with local users. A single click opens a device, as in the reference app.
- **2026-10-29 — Server services and the web browser.** TCP, DNS and HTTP on the wire; servers run HTTP (file manager), DNS (A records) and DHCP pools from a Services tab like the reference app's; PCs browse by name in a Web Browser; ACLs and NAT understand TCP ports; services sample lab.
- **2026-10-29 — Simulation Panel, Desktop and Config like the reference app.** From black-box screenshots: the Simulation Panel table and controls, play controls in the time bar, the navy PC Desktop with tiles, the router Config tab with Global Settings (display name vs hostname, NVRAM, startup/running config load, export and merge).
- **2026-10-29 — Dynamic routing, ACLs, NAT, DHCP relay.** OSPF (single area, computed convergence); numbered and named ACLs with match counts; static NAT, NAT pools and PAT; DHCP relay with `ip helper-address`; OSPF and NAT/ACL sample labs.
- **2026-10-29 — Spanning tree and switch management.** Per-VLAN spanning tree (root election, root/designated/alternate ports, priorities, portfast, `show spanning-tree`, amber lights); switch VLAN interfaces and default gateway; spanning-tree sample lab.
- **2026-10-29 — DHCP, device security, drawings.** DHCP server on routers (pools, exclusions, bindings, conflict detection) and DHCP clients on hosts; `enable secret`, console/vty passwords with real password prompts, banner, password encryption; rectangle, ellipse and line drawings on the workspace; a DHCP and security sample lab.
- **2026-10-29 — More devices and workspace notes.** Device catalogue with generic models (routers, switches, a hub, PC, laptop, server, printer); hubs repeat frames; notes placed on the workspace; copy/paste of devices; fuller toolbars.
- **2026-10-29 — Reference-app look.** Main window rearranged like the app learners know (menus, two toolbars, navy workspace and time bars, Realtime/Simulation switch, device box, scenario PDU list, Simulation Panel); device windows with Physical / Config / CLI / Desktop / Attributes tabs; Inspect tool. All artwork drawn in code. See `docs/ui-parity.md`.
- **2026-10-29 — M0 foundations.** Workspace with the Craft layout and gates; wire formats; lab model and file format; discrete-event simulator (switching, VLANs, routing, ARP, ICMP, proxy ARP, loop guard); console shell with configuration round-trip; engine command catalog with undo/redo and panic guard; egui app (canvas, consoles, event list with replay and pcap); CLI, MCP, web build.
